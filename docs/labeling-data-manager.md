# 标注配置、模板编辑与数据管理器交付记录

日期：2026-10-17。对照本机 `http://localhost:8080` 的 Label Studio **1.24.0.dev0**、原仓库和首次功能清单 F033–F080。使用原生 QML / Qt Quick Material、C++17、MSVC，保留 Django 后端与中英文即时切换。

界面参考网页的配置侧栏、Code/Visual 切换、模板分类卡片、预览画布，以及数据管理器标签页、工具栏、筛选弹窗/固定侧栏、表格/网格和任务快速查看。采用 Material 控件，布局尽量接近网页；不承诺逐像素一致。

文本标注支持多项 TextArea 独立输入、Choices、Rating 和 Number；清空数值会真正移除该结果。图片支持多帧、多来源区域及撤销重做。掩膜、音视频、时序等引擎不在本次实现范围。

## 验证及复现

- `.\build.ps1 -Test`：MSVC 构建与 language、document、api、native_ui、live_django 五组自动测试；默认 live_django 跳过真实写入。
- `.\tests\run-editor-data-live.ps1`：创建随机凭据的隔离组织、项目和 65 条任务；真实验证筛选/视图/列布局/全选排除/队列、批量动作、模板与配置、文本及混合多图片标注的保存重载；直接核验 Django 数据库，结束后清理自己的数据。
- `.\tests\run-project-live.ps1`、`.\tests\run-account-live.ps1`：此前账户和项目管理回归。
- 截图位于 `build-msvc/editor-data-screenshots/`，覆盖中英文、1060×700 最小窗口、表格/网格、筛选/标签页、配置代码/可视化/模板及真实任务。

日志：`build-msvc/editor-dm-build.log`、`editor-data-live-results.txt`、`editor-data-live-run.log`；部署验证见 `editor-dm-deploy.log` 与 `editor-dm-startup.log`。测试脚本不存储实际用户凭据，不写用户项目。

已验证 MSVC 五组 CTest 全部通过（默认真实写测试跳过），隔离配置/数据管理器两项往返与数据库核验通过，账户和项目隔离回归分别 3 passed / 0 failed。部署程序使用 Windows 平台插件成功启动并截图，退出码 0，启动诊断为空。代码复核发现的批量操作绕过未闭合多边形保护已接入共享 guard，并增加提示/取消保留草稿的 UI 回归。中文目录 707 项均已完成翻译，含 69 个动态模板标题。

## 主要代码

- `src/labelingconfig.*`：DOM 编辑、模板目录、语法高亮和补全。
- `qml/LabelingSetup.qml`、`LabelingPreview.qml`、`ConfigNode.qml`：编辑器及原生动态预览/控件。
- `src/annotationdocument.*`、`qml/AnnotationCanvas.qml`、`Workspace.qml`：结果模型、原生画布、任务侧栏/详情。
- `src/datamanager.*`、`qml/ProjectPage.qml`、`DataFilters.qml`、`DataColumns.qml`、`DataActionDialog.qml`：数据管理模型及页面。
- `scripts/sync-template-catalog.py`：从本机 Label Studio 源码重新生成打包模板；`scripts/update-translations.py` 同步翻译并保留动态模板标题。
